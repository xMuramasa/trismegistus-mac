Inter and JetBrains Mono, the same fonts the app bundles since #33; the Tokens page and the token set "Trismegistus" hold the values of `design/tokens.json`.

- `09f-sections-secondary-sidebar.png`: 09e with the sidebar on `secondary` `#666666` (Martin): titles white, meta lines and the header `on-steel` `#E9E9E9` (≈4.7:1), the selected row a white card with the yellow outline, the filter field light, the rule `on-steel` at 24%, icons `rule` `#D9D9D9`, the selected icon white over a yellow bar
- `09g-sections-native-sidebar.png`: 09e with the native macOS sidebar material (Martin asked for the native option). Penpot has no backdrop blur, so the material is simulated as an image fill: the Mac's wallpaper where the sidebar would sit, blurred, saturation ×1.6, under 80 % white (≈`#D3C9C9` here; it changes with the wallpaper and window position). In the app: `NSVisualEffectView` `.sidebar`, behind-window blending. Unselected icons `secondary`: `muted` falls under 2:1 on it, and `secondary` text reaches ≈3.5:1
- `09h-sections-floating-glass-sidebar.png`: the sidebar as a floating glass panel like Xcode on macOS 26 (Martin's Xcode screenshot): inset 8 pt, radius 18, full window height with the traffic lights and the sidebar toggle inside it; the steel top bar starts right of it; the section icons as Xcode's navigator row under the traffic lights (the selected one in a yellow circle); the list; `+` and a capsule filter field at the bottom. Material simulated as in 09g. In the app: our `SidebarSplit` column with `.glassEffect` (macOS 26) rather than going back to `NavigationSplitView`, and the top bar's steel drawn over the detail column only

These are a review artifact, not assets: the app draws everything in SwiftUI.
